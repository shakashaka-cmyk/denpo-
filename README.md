# デンポー！！ Webアプリ

文字数制限でヒントを出す、創意工夫のゲーム「デンポー！！」をWebで実装しました。

## 技術スタック

- **フロントエンド**: React 18 + CSS3
- **バックエンド**: Go 1.21 + Gorilla Mux
- **通信**: REST API + WebSocket

## ゲームルール

### 基本ルール
1. **親の設定**: 親がゲームの答えを決定
2. **ヒント出題**: 子たちが少ない文字数でヒントを出す
3. **解答フェーズ**: 30秒以内に正解を答える
4. **得点計算**: `18 - (文字数 ÷ 順番)` ※小数点切り上げ
5. **親を2周**: 各プレイヤーが親として2回担当
6. **合計得点で優勝**: 2周分の得点を合計して勝敗決定

### 得点の特徴
- **文字数が少ないほど高得点** → 短く的確なヒントが有利
- **後のヒントも価値がある** → 順番で割るため後出しでも工夫次第で得点可能
- **親と解答者に同点** → 親と子の協力感が生まれる

## セットアップ手順

### 1. バックエンド（Go）のセットアップ

```bash
# プロジェクトディレクトリに移動
cd denpou-backend

# 依存関係をインストール
go mod download

# サーバーを起動（ポート8080）
go run main.go
```

サーバーが起動すると、`http://localhost:8080` でAPI待機状態になります。

### 2. フロントエンド（React）のセットアップ

別のターミナルウィンドウで：

```bash
# プロジェクトディレクトリに移動
cd denpou-frontend

# 依存関係をインストール
npm install

# 開発サーバーを起動（ポート3000）
npm start
```

ブラウザが自動で開き、`http://localhost:3000` でアプリが起動します。

## API エンドポイント一覧

### ゲーム作成
```
POST /api/games
Content-Type: application/json

{
  "players": [
    { "name": "プレイヤー1" },
    { "name": "プレイヤー2" },
    { "name": "プレイヤー3" }
  ]
}
```

**レスポンス**: ゲームオブジェクト（gameId、プレイヤー、ラウンド情報を含む）

### ゲーム情報取得
```
GET /api/games/{gameId}
```

**レスポンス**: 現在のゲーム状態

### ラウンド開始
```
POST /api/games/{gameId}/rounds/{roundNumber}/start
Content-Type: application/json
X-Player-ID: {parentPlayerId}

{
  "answer": "答えの文字列"
}
```

**機能**: 親が答えを設定し、ヒント出題フェーズを開始

### ヒント投稿
```
POST /api/games/{gameId}/rounds/{roundNumber}/hints
Content-Type: application/json
X-Player-ID: {childPlayerId}

{
  "text": "ヒントのテキスト"
}
```

**レスポンス**: 投稿されたヒントオブジェクト（文字数、順番、スコア含む）

### 解答投稿
```
POST /api/games/{gameId}/rounds/{roundNumber}/answer
Content-Type: application/json
X-Player-ID: {playerId}

{
  "answer": "解答文字列"
}
```

**機能**: ラウンドの解答を受け取り、正誤判定と得点計算を実行

### WebSocket接続
```
WS /api/games/{gameId}/ws
```

**機能**: ゲーム状態をリアルタイム配信（1秒ごとに更新）

## 開発時のトラブルシューティング

### バックエンドエラー: "アドレスは既に使用されています"
```bash
# ポート8080が既に使用されている場合は、以下でプロセスを確認
lsof -i :8080

# または別のポートで起動
go run main.go -port 8081
```

### フロントエンドエラー: "APIに接続できない"
- バックエンドが `http://localhost:8080` で起動しているか確認
- ブラウザの開発者ツール（F12）でNetwork タブを確認
- CORS設定がバックエンドで有効になっているか確認

### リアクティビティの問題
- WebSocketの接続状態を確認
- 複数ブラウザでテストする場合、別プロセスで実行確認

## 機能概要

### セットアップ画面
- プレイヤー名を入力（2～4人推奨）
- ゲームルール表示
- ゲーム開始ボタン

### ゲーム画面
1. **親フェーズ**: 答えを入力 → ヒント受付開始
2. **ヒント出題フェーズ**: 子がヒントを投稿 → 文字数・スコアが自動計算
3. **解答フェーズ**: タイマー表示（30秒）→ 解答入力
4. **ラウンド終了**: 正誤表示 → 得点加算 → 次ラウンドへ
5. **最終結果**: 全ラウンド終了後、順位表示

### スコアボード
- リアルタイムで各プレイヤーの得点を表示
- 親交代時に自動更新

## パフォーマンス最適化

- フロントエンド: React.memo、useCallback による再レンダリング最適化
- バックエンド: インメモリデータ保存（本番環境ではDB使用推奨）
- WebSocket: 1秒間隔でのバッチ更新により不要な通信削減
